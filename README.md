# Rahil Mokashi — Portfolio

Personal portfolio site: a single `index.html` with a Three.js scene, GSAP scroll animations and no build step.

**Live:** https://rahil-mokashi.github.io/my-portfolio/

## Run locally
Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

## Hosting
GitHub Pages → Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
